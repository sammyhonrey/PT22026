# Python dependencies for the Advanced Music Recommendation System.
# Install with:  python -m pip install -r requirements.txt
#
# Target environment: Python 3.12 (verified on 3.12.10, Windows).
# Python 3.15 is NOT usable on this machine: its newer pandas, scikit-learn and
# matplotlib builds are blocked by Windows Smart App Control.
#
# The versions below were installed successfully on Python 3.12.10 (2026-11-18)
# and each package passed an individual import test. That confirms the packages
# load and are importable; it does not mean every feature of every library was
# exercised. The project's own behaviour is checked separately by the test
# suite (see tests/).
#
# Known limitation: Windows Smart App Control blocks pyarrow's filesystem
# extension, so `pyarrow.fs` and `pyarrow.parquet` fail to import. Core pyarrow,
# pyarrow.compute, pyarrow.csv and pyarrow.ipc work, which is what Streamlit
# needs. This project reads its dataset from CSV via pandas, so Parquet support
# is not required. Do not pin a different pyarrow version; the CSV workflow is
# sufficient.

# Machine learning
