# Example hourly CSV files

The two CSV files in this directory are small excerpts from the public datasets used by EcoWatt AI.

| File | Source and purpose |
|---|---|
| `xky_2025_demo_hourly.csv` | XKY 2025 Subject 14 example. Dataset DOI: [10.57745/MA43FS](https://doi.org/10.57745/MA43FS); selected source file DOI: [10.57745/OILZFV](https://doi.org/10.57745/OILZFV). |
| `uci_demo_hourly.csv` | UCI Household Electric Power Consumption example. Dataset DOI: [10.24432/C58K54](https://doi.org/10.24432/C58K54). |

These files help users inspect the CSV input format and try the data-validation flow. They are not synthetic replacements for the full datasets.

The full source datasets are not included. See the top-level `README.md` for the official sources, licences and preparation commands.
